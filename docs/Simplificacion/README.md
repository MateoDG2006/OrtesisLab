# Simplificación

**Propósito:** recoger qué responsabilidades escritas a mano pueden pasar a
librerías, o a funciones de dependencias ya instaladas, y en qué orden hacerlo.
Son documentos de propuesta: describen el código vigente al 2026-11-12 y no
cambios implementados.

| Documento | Responde a |
|---|---|
| [INVESTIGACION_LIBRERIAS.md](INVESTIGACION_LIBRERIAS.md) | Qué código propio existe, qué librerías se evaluaron, con versiones y licencias, el veredicto de cada una, y los defectos encontrados durante la revisión |
| [PLAN_SIMPLIFICACION.md](PLAN_SIMPLIFICACION.md) | Qué librería asume cada responsabilidad, qué se elimina sin reemplazo, y las fases con su verificación |

Cualquier implementación exige antes la autorización y el registro descritos en
[docs/Audit/README.md](../Audit/README.md).
